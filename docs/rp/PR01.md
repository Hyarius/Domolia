# PR01 — Socle Android, identité et distribution

> **Statut :** Fusionnée · **Dépendance :** Aucune · **Dépôt :** `Hyarius/Domolia`

## Résultat visible dans l'application

Domolia s'installe sur Android avec son thème vert/or et un canal GitHub de préversions utilisables.

## Périmètre de la PR

- Application Flutter locale, écran initial, navigation minimale et identité graphique Domolia.
- GitHub Actions : analyse, tests, génération d'APK pour les branches de travail et `dev-latest` sur `main`.
- Signature Android persistante via secrets GitHub Actions, lien de téléchargement et README d'installation.

## Contraintes d'architecture et règles métier

- Application Android locale ; aucun backend hébergé nécessaire.
- Ne jamais versionner le keystore ou ses mots de passe.

## Critères d'acceptation et tests

- Une PR produit un APK de test et une branche poussée produit sa préversion GitHub téléchargeable.
- Le certificat de l'APK release correspond à la clé conservée par le propriétaire.
- L'accueil Domolia et la navigation s'affichent sur un téléphone Android.

Les tests unitaires et widgets doivent couvrir les règles ajoutées. Tout scénario nécessitant un fournisseur distant doit aussi avoir un test avec une réponse simulée. Si une modification concerne Android, elle doit être vérifiée dans l'APK de préversion de la branche.

## Hors périmètre

Aucun chat, aucune sauvegarde RP, aucun système de mise à jour en un clic. Document historique : ne pas réimplémenter cette PR.

## Règle de livraison

Cette PR doit être isolée sur une branche de travail, avoir sa CI verte et fournir une évolution testable sur Android. **Ne jamais fusionner sans autorisation explicite du propriétaire.** Le numéro `PR01` est le numéro logique de feuille de route, indépendant du numéro de Pull Request attribué automatiquement par GitHub.
