# PR02 — SQLite Web / IndexedDB et persistance

## Périmètre

- Ajouter la cible Flutter Web sans application indépendante, isoler le bootstrap Android vs Web et choisir la factory SQLite par plateforme.
- Ajouter `sqflite_common_ffi_web` et ses fichiers `sqlite3.wasm` / `sqflite_sw.js` selon la version résolue ; une seule base nommée `domolia_books.sqlite` par origine.
- Faire fonctionner BookStore sur Web : Livres, couvertures base64, Parties, événements et profils liés ; préserver la migration v2→v3 si PR #7 a fusionné.
- Gérer les erreurs IndexedDB, quotas, arrêt pendant l'écriture, version de schéma, deux onglets et Worker non partageable.
- Demander `navigator.storage.persist()` lorsqu'offert, sans bloquer la fonction en cas de refus. Avertissement de stockage local et état réel visible.
- Ne jamais basculer en mode mémoire silencieusement. Android reste sur son store actuel.

## Validation d'acceptation

- Création → rechargement → fermeture complète → réouverture, sans perte d'un Livre, d'une couverture, d'une Partie, d'un profil lié ou d'un séparateur de scène.
- Migration d'une base ancienne et écriture concurrente vérifiées dans Firefox, Chrome et Edge.
- Collision d'onglets non destructrice même si un SharedWorker n'est pas disponible.
- `flutter analyze`, `flutter test`, compilation Web et CI Android sans régression ; résultat et navigateur réel consignés.
- Aucune fusion sans accord.
